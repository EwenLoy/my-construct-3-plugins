## 📦 Dictionary Plus

  <img width="60" height="60" src="https://github.com/user-attachments/assets/1da611a5-4e51-4c09-a5c6-0e61ab388da9" />

**Dictionary+** — это расширенная версия стандартного плагина Dictionary для Construct 3, дополненная встроенными инструментами для постоянного хранения данных.

### ✨ Ключевые фишки
- 🚀 **Native Experience:** Полная совместимость со стандартной логикой Construct.
- 💾 **Persistent Storage:** Мгновенное сохранение и загрузка данных в `localStorage` (Save/Load slots).
- ⚙️ **Worker Mode Ready:** Стабильная работа в режиме **Web Worker** без ошибок доступа.
- 🛠️ **Enhanced Debugger:** Панель отладки со счетчиком ключей и живым редактированием.
- 📂 **JSON System:** Быстрый импорт/экспорт и поддержка скачивания данных.

### ❓ Почему стоит использовать?
В обычном словаре вам нужно вручную связывать его с плагином LocalStorage. **Dictionary+** делает это за вас "под капотом", избавляя от лишних событий в коде и снижая риск ошибок при сохранении прогресса.
